# IDC Web

This repository contains a small playful single-page React app (Vite) "IDC." — a pixel-style interactive joke.

How to run locally:

1. Clone:
   git clone https://github.com/hassanabdulhussien/Idc-web.git
2. Install:
   npm install
3. Dev server:
   npm run dev

Build:

npm run build

Deploy on Vercel:
- Create a Vercel account and connect your GitHub.
- Import the repository; Vercel will use `npm run build` and the `dist` output.
